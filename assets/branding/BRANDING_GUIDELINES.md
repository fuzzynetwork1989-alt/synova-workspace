# Synova Branding Guidelines

This document outlines the visual identity and branding guidelines for the Synova project.

## Brand Overview

**Synova** is an advanced AI workspace that combines cutting-edge technology with elegant design. Our brand represents innovation, reliability, and accessibility in AI development.

## Logo Usage

### Primary Logo

The primary Synova logo should be used in most applications:

- **File**: `logos/synova-logo-primary.svg`
- **Minimum Size**: 120px (width)
- **Clear Space**: Maintain at least 20px of clear space around the logo
- **Background**: Works on both light and dark backgrounds

### Logo Variations

- **Horizontal**: `logos/synova-logo-horizontal.svg` - For wide spaces
- **Vertical**: `logos/synova-logo-vertical.svg` - For narrow spaces
- **Icon**: `logos/synova-icon.svg` - Standalone icon for favicons and small spaces
- **Monochrome**: `logos/synova-logo-monochrome.svg` - For single-color applications

### Logo Don'ts

- Do not stretch or distort the logo
- Do not change the colors without approval
- Do not add effects or shadows
- Do not rotate the logo
- Do not use outdated versions

## Typography

### Font Family

- **Primary**: Inter (sans-serif) - For UI and body text
- **Heading**: Poppins (sans-serif) - For headings and titles
- **Code**: Fira Code (monospace) - For code and technical content

### Font Sizes

| Size | Usage |
|------|-------|
| 12px | Small text, captions |
| 14px | Body text, default |
| 16px | Large body text |
| 18px | Subheadings |
| 24px | Section headings |
| 32px | Page headings |
| 48px | Hero headings |

### Font Weights

- **Regular**: 400 - Body text
- **Medium**: 500 - Emphasis
- **Semibold**: 600 - Subheadings
- **Bold**: 700 - Headings

## Icons

### Icon Set

Synova uses a custom icon set located in `icons/`:

- **Size**: 24x24px (default)
- **Stroke Width**: 2px
- **Style**: Outline style with rounded corners
- **Color**: Inherit from text color or use primary brand color

### Icon Usage

- Use icons consistently throughout the application
- Pair icons with labels when possible
- Maintain proper spacing around icons
- Use appropriate icons for their context

## Imagery

### Photography Style

- Clean, modern aesthetic
- Focus on technology and innovation
- Natural lighting preferred
- Diverse representation

### Illustration Style

- Geometric, minimalist approach
- Consistent color palette
- Rounded corners and soft edges
- Professional and approachable

## Voice & Tone

### Brand Voice

- **Professional**: Knowledgeable and credible
- **Approachable**: Friendly and accessible
- **Innovative**: Forward-thinking and modern
- **Reliable**: Trustworthy and dependable

### Tone Guidelines

- Use clear, concise language
- Avoid jargon when possible
- Be helpful and supportive
- Maintain consistency across all communications

## Social Media

### Profile Images

- **Avatar**: `logos/synova-icon.svg` (square format)
- **Banner**: `banners/social-media-banner.png` (1500x500px)
- **Size**: Optimize for each platform

### Hashtags

- Primary: `#SynovaAI`
- Secondary: `#AIWorkspace`, `#SynovaWorkspace`

## File Formats

### Recommended Formats

- **Logos**: SVG (preferred), PNG (for web)
- **Icons**: SVG (preferred), PNG (for web)
- **Banners**: PNG, JPG (optimized)
- **Photography**: JPG (optimized), WebP (modern browsers)

### Specifications

- **Web**: Optimize for web (72 DPI)
- **Print**: High resolution (300 DPI)
- **Social**: Follow platform specifications

## Accessibility

### Color Contrast

- Ensure WCAG AA compliance (4.5:1 minimum for text)
- Test color combinations for colorblind users
- Avoid color as the only indicator

### Typography

- Maintain readable font sizes (minimum 14px for body text)
- Use sufficient line spacing (1.5 minimum)
- Ensure proper heading hierarchy
