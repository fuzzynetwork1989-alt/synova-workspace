## 🚀 DEPLOYMENT INSTRUCTIONS

### 📱 MOBILE APP DEPLOYMENT

#### EXPO GO BUILD
```bash
cd repos/synova-mobile
npm install
npm run build:android    # Android APK
npm run build:ios        # iOS IPA
npm run build:all        # All platforms
```

#### APK INSTALLATION
1. **Download APK**: Get the built APK file
2. **Enable Unknown Sources**: Settings > Security > Unknown sources
3. **Install APK**: Open the downloaded file
4. **Launch App**: Find "Synova AI" on your device

#### EXPO GO INSTALLATION
1. **Install Expo Go**: Download from app store
2. **Scan QR Code**: Use `expo start` QR code
3. **Launch App**: Opens automatically in Expo Go

### 🌐 WEB DEPLOYMENT

#### DEVELOPMENT
```bash
cd repos/synova-web
npm install
npm run dev
```

#### PRODUCTION
```bash
cd repos/synova-web
npm run build
npm start
```

#### DESKTOP INSTALLATION
1. **Build Web App**: `npm run build` creates static files
2. **Serve Locally**: Use any static server (Serve, Vercel, etc.)
3. **Install PWA**: Access via browser -> "Add to Home Screen"

### 🔧 API DEPLOYMENT

#### START PRODUCTION
```bash
cd repos/synova-core-api
npm install
npm start
```

#### DOCKER DEPLOYMENT
```bash
docker build -t synova-ai .
docker run -p 8001:8001 synova-ai
```
