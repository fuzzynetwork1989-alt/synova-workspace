## 10. API Usage

### Authentication

Use your API key or JWT token:

```bash
curl -X POST https://api.synova.ai/brain/chat \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Hello"}'
```

### Python Example

```python
import requests

API_KEY = "your-api-key"
BASE_URL = "https://api.synova.ai"

headers = {
    "Authorization": f"Bearer {API_KEY}",
    "Content-Type": "application/json"
}

response = requests.post(
    f"{BASE_URL}/brain/chat",
    headers=headers,
    json={
        "user_id": "user_123",
        "prompt": "Explain quantum computing",
        "complexity": 0.7
    }
)

print(response.json())
```

### Streaming Responses

```python
import requests

response = requests.post(
    f"{BASE_URL}/api/chat/stream",
    headers=headers,
    json={"prompt": "Tell me a story"},
    stream=True
)

for chunk in response.iter_lines():
    if chunk:
        print(chunk.decode())
```

### Rate Limits

- Free tier: 100 requests/minute
- Pro tier: 1,000 requests/minute
- Enterprise: Unlimited

### Error Handling

```python
response = requests.post(url, headers=headers, json=data)

if response.status_code == 429:
    print("Rate limited. Wait and retry.")
elif response.status_code == 401:
    print("Invalid token.")
elif response.status_code == 500:
    print("Server error. Try again later.")
```

## 12. Best Practices

### For Better Results

**Be Specific**
- Instead of: "Write code"
- Try: "Write a Python function to sort a list of dictionaries by date"

**Provide Context**
- Include relevant background information
- Specify constraints and requirements
- Mention preferred approaches

**Use Appropriate Complexity**
- Simple questions: Low complexity
- Analysis: Medium complexity
- Novel problems: High complexity

**Iterate**
- Start with a basic query
- Refine based on initial response
- Ask follow-up questions

### Security Best Practices

- Never share your API key
- Use environment variables for secrets
- Rotate tokens regularly
- Use HTTPS in production
- Monitor usage for anomalies

### Performance Tips

- Use streaming for long responses
- Cache frequently used data
- Batch similar requests
- Use appropriate complexity levels
